# Moon Board V1 Design Notes



This board is designed to get the absolute position of a single motor shaft. It sits right next to it on the motor in a side-shaft configuration (possible because they have worm gearboxes).



The components are only on one side and the PCB is basic, but to fabricate it along with the Sun and Planet boards it also has 4 layers.



### Connectors

The same connectors as the motors are used between the Planet and Moon board to simplify the BOM.



### Absolute Encoders

The absolute encoders used in this project are MagAlpha, an angle sensor measuring the magnetic field generated by a magnet fixed on the other side of the joint (so the shaft here).

The magnet is a diametric ring magnet, put on the joint around the shaft.
